# Hartmann 1909 → 1921 → 1936：Problemgeschichte 的时间分层

> 状态：method-lineage correction / source packet  
> 目的：避免把 Hartmann 成熟期的 `Problemgehalt / Problemlage / Problemstellung` 三分法直接倒投到 1909 年方法论文。  
> 边界：本包不否认 1909 已经主张跨历史的问题连续性；它区分“1909 能直接证明的命题”与“1921/1936 才能明确绑定的成熟术语体系”。

## 1. 新增发现

当前仓库正确抓住了 Hartmann 式 Problemgeschichte 的核心危险：跨时代 problem identity 容易被预先假定。但 source audit 后，需要把 Hartmann 自己拆成时间层。

目前最稳妥的图是：

~~~text
1909/1910 — Zur Methode der Philosophiegeschichte
  已明确：
  - philosophical problems 有跨历史连续性；
  - “problem itself” 被主张为稳定；
  - 历史变化主要落在问题被意识、把握和处理的程度；
  - 哲学史应围绕 problems / insights，而不是 thinker systems 组织。

1921 — Grundzüge einer Metaphysik der Erkenntnis
  可明确绑定成熟三层 distinction：
  - Problemstellung
  - Problemlage
  - Problemgehalt

1936 — Der philosophische Gedanke und seine Geschichte
  在成熟的 philosophy-history 语境中重新展开：
  - Problemstellungen / Problemfassungen 会变化；
  - Problemlage 会变化；
  - eigentliche Problemgehalte 被主张为跨时代保持同一。
~~~

因此：

~~~text
1909 enduring-problem thesis
!=
proof that the full later triad
was already formulated in 1909
~~~

这暴露出一个本项目必须防止的风险：

> 同一作者后来把早期立场表达得更系统，不等于后来的概念结构可以无标记地当作早期文本自己的 formulation。

## 2. 1909/1910：已经能安全恢复什么

Nicolai Hartmann, “Zur Methode der Philosophiegeschichte,” *Kant-Studien* 15 (1909/1910), 459–485；1958 重印于 *Kleinere Schriften* III, pp. 1–22.

书目控制：

- https://philpapers.org/rec/HARZMD-5
- https://doi.org/10.1515/9783110855203.1

原刊或 1958 重印的公开逐页扫描目前仍未恢复，因此 exact wording 需要标明 source mediation。

Hannes Kerber 的研究对 1909 reprint 给出精确页码：p.14 用于 Hartmann 的 problem-continuity thesis，p.15 保存 problems 的 unity / historical continuity。另一份学术转录保存了 reprint p.10 的关键句开头：

> “Das Problem selbst als solches steht fest …”

所以对 1909 最安全的 actor-level 重建是：

> 如何写出一种真正属于哲学自身的历史，使思想家与体系的历史变化不把哲学分裂成互不相关的意见，同时又不靠先验系统把历史强行构造出来？

Hartmann 的 answer 是：以 problems / insights 的连续性而不是 thinker systems 为主轴；problem 本身具有相对独立和持续的地位。

这已经足够支持本项目的核心警告：

~~~text
Hartmann 1909:
historical variation does not finally alter
the problem itself

Problem History:
whether the “problem itself” survives
must itself be demonstrated
~~~

## 3. 1921：三层 distinction 的明确 source binding

Nicolai Hartmann, *Grundzüge einer Metaphysik der Erkenntnis*, first edition 1921.

控制来源：

- https://philpapers.org/rec/HARGEM-14
- Stanford Encyclopedia of Philosophy:
  https://plato.stanford.edu/entries/nicolai-hartmann/

SEP 明确规定 `ME = Grundzüge einer Metaphysik der Erkenntnis`，并在讨论 Hartmann problem concept 时区分：

- `Problemstellung`
- `Problemlage`
- `Problemgehalt`

完整论述被绑定为 **ME1b**。因此成熟三层结构至少可以安全地绑定到 1921 *Metaphysik der Erkenntnis*，不需要假设它已经以同样形式存在于 1909。

成熟结构可概括为：

~~~text
Problemstellung
  人怎样提出 / 表述问题；
  可有个人与体系特征

Problemlage
  某一历史传统中问题达到的状态；
  随知识和历史工作发生变化

Problemgehalt
  Hartmann 认为并非由人任意制造；
  与世界和人的基本结构一起被给予；
  在成熟理论中承担跨历史 identity
~~~

## 4. 1936：成熟的 philosophy-history restatement

Nicolai Hartmann, *Der philosophische Gedanke und seine Geschichte*, Berlin: Verlag der Akademie der Wissenschaften, 1936, 47 pp.

书目：

- https://ci.nii.ac.jp/ncid/BA32161036
- https://katalog.slub-dresden.de/id/0-1076122957

Kerber 在讨论 Hartmann problem differentiation 时，把 `Problemstellungen / -fassungen`、`Problemlage`、`Problemgehalte` 的核心成熟表述绑定到 1936 p.4，并列出 pp.13, 16, 19, 21, 27f., 30, 33f., 45f.；同时把 1921 pp.12–15 和 1933 self-presentation 作为平行材料。

因此目前最安全的时间图是：

~~~text
1909:
strong continuity thesis
+
problem itself treated as stable

        ↓

1921:
explicit differentiated problem ontology

        ↓

1936:
mature historiographic restatement
and methodological deployment
~~~

这里的箭头只是同一作者内部的发展候选，不等于“无变化的同一 doctrine”。

## 5. 三层严格分离

### Historical actor — Hartmann 1909

问题：怎样使哲学史既是真正的 history，又保留 philosophy 自身的客观连续性，而不沦为 biography、system history 或历史相对主义？

回答方向：以 problems / insights 的连续性组织哲学史。

### Historical actor — Hartmann 1921

问题进入 cognition / ontology：当人的 problem statement 具有历史性，而 problem 又不被人任意制造时，怎样区分 formulation、historical state 与 problem content？

这里才适合明确记录 `Problemstellung / Problemlage / Problemgehalt`。

### Historical actor — Hartmann 1936

成熟问题：怎样说明 philosophical problems 能跨时代连接 thinkers，同时又允许具体 Problemlage 与 Problemstellung 变化？

### Later reconstruction

- Kerber：恢复 Hartmann 成熟 Problemgeschichte，并把他作为 Gadamer 批判的重要对象；
- Renz：把 1909 方法论文放回 Marburg philosophy historiography 的形成场；
- SEP：用 Hartmann 全部著作系统化三层 problem concept。

### Researcher-side rule

~~~text
same author
+
later explicit conceptual articulation

!=

proof that the earlier source
already contained that articulation
~~~

## 6. 新 hindsight-risk fixture：same-author backprojection

发生方式：

~~~text
Actor A at t1
states an early thesis

        ↓

Actor A at t2
develops sharper vocabulary

        ↓

historian uses t2 terminology
to summarize t1

        ↓

the summary is later cited
as if t1 itself had said it
~~~

暂时建议在研究包中区分：

~~~text
contemporaneous_actor_formulation
same_actor_later_reformulation
later_historian_reconstruction
researcher_analytic_abstraction
~~~

先不改 schema / validator。

## 8. 对现有 Hartmann–Gadamer 包的修正

核心对比仍成立：

~~~text
Hartmann 1909:
problem itself can remain fixed
while historical grasp varies

        vs

Gadamer:
historicity can enter
what becomes problematic
and what the problem contains
~~~

需要修正的只是：

> 不再把 1921/1936 的成熟三分法无标记地叫作“1909 的 hierarchy”。

## 10. 后见之明风险

- 把成熟术语倒投到青年文本；
- 把 later self-clarification 当作 original intention 的透明窗口；
- 把 intellectual development 压成静态 doctrine；
- 因 mature formulation 更清楚，就让它替代 earlier episode；
- 从“同一作者”直接推出“同一 problem formulation”。

## 11. 尚不确定

- 1909 原刊 / 1958 reprint direct images；
- 1909 是否已经个别使用三术语，以及是否构成完整 triad；
- 1921 first edition pp.12–15 direct images；
- 1936 p.4 及相关页 direct images；
- 1921 是否是 triad 的首次出现；
- 1909→1921 是概念深化、ontological turn，还是早期未展开思想的术语化。

## 13. 本轮方法结论

~~~text
historical actor at t1
!=
the same actor at t2
for formulation provenance

later self-clarification
may be evidence about development

but must not silently replace
the earlier historical question
~~~

因此：

> **问题同一性不能预设；行动者自身的跨时间同一性，也不能替 problem formulation 的跨时间同一性作担保。**
