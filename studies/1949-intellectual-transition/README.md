# 1949 断点测试：从“知识分子如何参与革命”到“国家如何组织、改造和使用知识”

> 这不是一篇“新中国成立史”。它只测试一个问题史命题：**中华人民共和国成立是否改变了“知识分子问题”的可问结构。**

## 暂定结论

1949 不应被机械地当作年代分界，但它提供了一个很强的制度断点：全国性国家建立以后，知识、教育、文学艺术不再只是社会运动、思想争论或革命动员中的力量，也被明确写进国家建设、人才培养和制度组织之中。

因此，原本可以围绕“知识分子站在哪一边”“文学如何参与民族/革命事业”提出的问题，在 1949 后出现了新的问题层：

```text
国家已经成立
    ↓
谁来建设、管理、教育、研究、创作？
    ↓
旧社会形成的知识人能否进入新国家？
    ↓
进入的条件是什么：政治立场、思想改造、专业能力、制度归属？
    ↓
国家怎样把知识转化成可持续的建设能力？
```

这个变化不是“旧问题得到答案”，而更像是**国家成立制造了一个新的问题场**。

## 为什么选 1949—1956

这里先做三个 episodes：

1. **1949：建国与全国性组织化**——知识/文艺开始被明确置入国家建设、人才培养和全国性组织结构；
2. **1951：思想改造与政治位置**——问题集中为旧知识分子如何适应新社会、站到人民和工人阶级立场；
3. **1956：知识能力与科学建设**——问题重心明显转向知识分子的数量、业务能力、使用条件以及追赶现代科学的国家能力。

三段材料之间存在明确历史传递，但不能轻率写成“同一个知识分子问题不断得到更好答案”。核心 presuppositions 和 answer space 都发生了变化。

## 目前建议的关系

关系端点引用每个 episode 首个 YAML metadata block 中的稳定 `episode_id`；文件名只用于阅读排序，重命名文件不得改变节点身份。

```yaml
relations:
  - from: 1949-state-building
    to: 1951-remolding
    type: transformed_successor
    confidence: medium

  - from: 1951-remolding
    to: 1956-science-construction
    type: transformed_successor
    confidence: high
```

第二条尤其重要：1956 的材料明确以“过去六年来”的变化为前提，说明它知道自己继承了 1951 前后的政策过程；但 1956 又重新界定了知识分子的社会位置，并把“发挥专业力量、追赶科学”推到问题中心，所以不宜只标 `continuous`。

## 这组 pilot 想检验什么

- 1949 是否真的改变了问题的 askability，而非只是政治纪年；
- “知识分子”同一个词在 1949、1951、1956 是否仍指向同一种问题对象；
- 国家制度建立后，`stakes` 是否从革命参与转成治理/建设能力；
- 1951 的“改造”与 1956 的“使用、培养、科学规划”能否被建成简单连续线；
- 能否保存：政治身份问题没有消失，但专业能力问题获得了新的中心地位。

## 核心材料

- 1949-07，第一次中华全国文学艺术工作者代表大会相关报告；
- 1949-09，《中国人民政治协商会议共同纲领》第五章“文化教育政策”；
- 1951-09-29，周恩来《关于知识分子的改造问题》；
- 1956-01，中共中央知识分子问题会议、周恩来《关于知识分子问题的报告》；
- 1956-01-31，郭沫若《在社会主义革命高潮中知识分子的使命》。

详见各 episode。

## 方法警告

这组材料很容易被写成后来政策史的目的论：

```text
1949 接管知识分子
→ 1951 改造
→ 1956 正确认识知识分子
```

仓库暂时拒绝这种写法。

我们需要同时保存：

- 每个时间点当时究竟认为“问题”是什么；
- 谁在提问；
- 当时可接受的答案有哪些；
- 后一个时期如何回看前一个时期；
- 变化来自思想修正、制度变化、建设压力，还是分类本身改变。
